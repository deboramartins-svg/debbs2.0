# 🛍️ Debbs' Finds — Vitrine de Achadinhos & Promoções

Uma aplicação web moderna e responsiva focada em curadoria e indicação de produtos, organizada como uma vitrine digital de achadinhos. O projeto centraliza links de afiliados e indicações imperdíveis das principais plataformas de e-commerce (como **SHEIN** e **Shopee**), oferecendo também um canal interativo de sugestões e feedback para os seguidores.

---

## 🚀 Demonstração Online

Acesse o projeto em funcionamento: [debbs2-0.vercel.app](https://debbs2-0.vercel.app)

---

## ✨ Principais Funcionalidades

* **Curadoria de Achadinhos:** Organização limpa e intuitiva de produtos e promoções divididos por categorias e lojas (SHEIN, Shopee e muito mais).
* **Links Diretos para Ofertas:** Facilita o acesso rápido do usuário aos produtos recomendados através de botões e atalhos otimizados.
* **Canal de Sugestões Interativo:** Seção dedicada para que os seguidores e clientes enviem opiniões, pedidos especiais e feedbacks diretamente.
* **Layout Focado em Mobile (Link in Bio / Vitrine):** Design leve e responsivo, ideal para ser utilizado em redes sociais (como Instagram e TikTok) como um agregador inteligente de links e recomendações.

---

## 🛠️ Tecnologias Utilizadas

* **Frontend:** JavaScript / Framework moderno baseado em componentes
* **Estilização:** CSS / Estilização responsiva personalizada
* **Deploy e Hospedagem:** Vercel
